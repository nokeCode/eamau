DOCUMENTATION TECHNIQUE

EAMAU Mobile API

API REST de la plateforme mobile universitaire EAMAU

Version 1.0.0 · Généré le 24/07/2026 15:00

Comment consommer l’API

Base URL : http://localhost:9090. Les endpoints sont versionnés sous /api/v1.

Pour les routes protégées, envoyer l’en-tête Authorization: Bearer <JWT>. La connexion est disponible avec POST /api/v1/auth/login.

Format de succès

{
    "success": true,
    "message": "Opération réussie.",
    "data": {
        "id": "..."
    },
    "meta": []
}

Format d’erreur

{
    "success": false,
    "message": "Erreur de validation.",
    "errors": {
        "field": [
            "Valeur invalide."
        ]
    },
    "code": 422
}
